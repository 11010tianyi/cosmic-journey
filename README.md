# 宇宙尺度之旅（Cosmic Journey）

一场第一人称感觉的对数尺度旅程：从可观测宇宙一直缩放到「你在这里」。页面带哲学摘引、可选定位问候、本地氛围乐，以及 2076 轨道殖民地 / 月球 / 火星场景。

线上站点：<https://11010tianyi.github.io/cosmic-journey/>

根地址会直接打开旅程。旧地址 <https://11010tianyi.github.io/cosmic-journey/cosmic_journey.html> 仍会进入同一件作品。

这是静态的 GitHub Pages 站点，没有服务器，也没有统计脚本。

## 本地打开

在仓库根目录起一个静态服务器（部分浏览器会限制 `file://` 上的定位、音频和贴图）：

```bash
python3 -m http.server 8080
```

浏览器打开 <http://127.0.0.1:8080/> 。

## 怎么游历

桌面：

- 滚轮或触控板缩放。捏合触控板（按住 Ctrl 的滚轮）同样有效。
- 右侧竖向滑杆拖动；圆点可跳到某一站。
- `+` / `−` 或方向键上下缩放，空格键自动播放，`R` 回到可观测宇宙，`F` 全屏，`End` 跳到「你在这里」。

手机和平板：

- 在画面上双指捏合，或单指上下滑动。
- 底部横滑杆和圆点用来跳站；按钮不小于 40px。
- 「哲」打开哲学与知识，「景」打开 2076 场景。它们默认收起，避免挡住星空。
- 横屏和竖屏都能从银河系缩放到「你在这里」。

地址栏会写成 `#at=milky-way` 这样的一站。刷新、或把链接发给别人，会从这一站继续，而不是回到介绍页之后的自动巡航。分享按钮会复制这条链接；手机上若系统支持，也会走系统分享。

若浏览器允许定位，靠近城市和「你在这里」时会出现坐标，并尝试反查地名和一句问候。拒绝定位不影响旅程。

## 尺度说明

滑杆和站名是叙事上的停靠点，画面没有按真实比例画行星或大陆。左上角的「此刻 ≈ 10ⁿ 米」跟着对数尺连续变化。各站距离是公开资料里的数量级，不是新的测量结果。

## 资源

- `space_scene_2076_colony.jpg`、`space_scene_2076_moon.jpg`、`space_scene_2076_mars.jpg` 是 2076 场景。
- `audio/cosmic_ambient.mp3` 是本地氛围乐。页面也会尝试 Kevin MacLeod 的 *Ghostpocalypse 6*（CC BY，incompetech.com）；远程失败时用本地文件。
- 地球表面在能加载时使用 three.js 示例里的公开地球贴图，失败则退回色块大陆。
- `相关性资源集/宇宙尺度之旅_全网高相关性项目清单.md` 是和这件作品相关的外部项目清单。
